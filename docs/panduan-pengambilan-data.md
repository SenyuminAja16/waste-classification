## 2\. Kelas

| Kelas | Masuk | Tidak masuk |
| :---- | :---- | :---- |
| **Plastik** | Botol, gelas cup, wadah/kotak plastik kaku, tutup, kresek | Sachet/bungkus snack berlapis foil, styrofoam, sedotan |
| **Kertas** | HVS/kertas print, koran, struk, kertas cokelat tipis, amplop, Tisu | kertas berlapis plastik/minyak (bungkus nasi), karton duplex |
| **Kardus** | Karton **bergelombang** (corrugated): kardus paket, kardus mi/air mineral, potongan kardus | Kotak sereal/obat/HP (duplex), tetrapak (kotak susu/jus) |

**Aturan kasus abu-abu**

1. **Label tidak mengubah kelas.** Botol berlabel tetap plastik. Kardus dengan lakban atau stiker tetap kardus.  
2. **Kardus harus corrugated.** Yang menentukan adalah lapisan bergelombang di dalamnya, bukan warna cokelatnya.  
3. **Kalau ragu, jangan difoto.**  
4. **Kertas tidak boleh berisi data pribadi** (nama, NIM, nilai, alamat, nomor HP). Lipat bagian sensitifnya atau keluarkan dari frame.

**Variasi di dalam kelas**

| Kelas | Sub-tipe | Catatan |
| :---- | :---- | :---- |
| Plastik | Botol, gelas cup, wadah/tutup, kresek | Kresek **maksimal 25%** objek plastik |
| Kertas | Lembaran utuh, diremas, dilipat/sobek, koran/struk | Seimbangkan antara utuh dan diremas |
| Kardus | Kotak utuh, potongan/lembaran, penyok/basah | Usahakan ada kardus berwarna/bercetak selain cokelat polos |

## 4\. Cara Memotret

**Per objek: 2 foto, urutan wajib**

1. **Atas**: tegak lurus dari atas objek  
2. **Miring ±45°**

**Framing**

- Objek di **tengah frame**, mengisi **±50–70%** frame, dan **tidak terpotong** tepi frame.  
- Jarak menyesuaikan ukuran objek. Yang jadi patokan adalah framing, bukan jarak dalam cm.  
- **Satu objek per foto.** Tidak boleh ada sampah dari kelas lain di frame.

**Latar**

- **±70% polos:** lantai keramik, meja polos, kasur/kain satu warna. Tidak ada benda lain di frame.  
- **±30% ramai** (per kelas): meja dengan barang lain, karpet/sprei bermotif, teras, paving, rumput. Tidak perlu pergi ke tempat khusus.  
- Sebisa mungkin latar kontras dengan objek. Contohnya, kertas putih jangan diletakkan di lantai putih.

**Pencahayaan**

- Variasikan **antar objek**: dekat jendela, lampu kamar, luar ruangan teduh atau terang.  
- **Flash mati.** Hindari backlight.  
- Pada foto dari atas, pastikan **bayangan HP atau tangan tidak menutupi objek**.

**Kondisi objek**

- Biarkan apa adanya, jangan dibersihkan atau dirapikan.  
- Usahakan bervariasi: bersih, kotor, penyok, lecek. Kresek dibiarkan seperti saat dibuang.

**Setelan HP** (atur sekali di awal)

- Kamera bawaan, mode **Foto** biasa. **Jangan pakai mode Portrait/bokeh.**  
- Zoom **1×**. Jangan pakai ultrawide (0,5×).  
- Rasio **4:3**, resolusi default. Jangan pakai mode 50/108/200 MP.  
- **Matikan:** flash, filter, beauty, AI scene optimizer, **tag lokasi/GPS**.  
- Format **JPG**. Untuk iPhone: Settings → Camera → Formats → *Most Compatible*.  
- Tap layar di objek untuk fokus.

**Foto harus diulang kalau:**

- Blur atau goyang  
- Objek terpotong atau terlalu kecil (di bawah ±40% frame)  
- Ada sampah dari kelas lain di frame  
- Terlalu terang atau terlalu gelap sampai tekstur tidak terlihat  
- Objek tertutup bayangan HP atau tangan  
- Ada wajah, orang, atau data pribadi

## 5\. Penamaan & Penyimpanan

**ID objek** \= `KELAS-ANGGOTA-NOMOR`

| Kode kelas | Kode anggota |
| :---- | :---- |
| `PL` plastik | `M` Mafaza |
| `KT` kertas | `F` Farhan |
| `KD` kardus | `J` Jefri |

Nomor berurutan per anggota per kelas, 3 digit: `PL-F-001`, `PL-F-002`, `KD-J-014`.

**Alur per sesi**

1. Memotret dengan urutan **atas dulu, lalu miring**.  
2. Hapus foto gagal di HP. Setiap objek harus punya **tepat 2 foto**.  
3. Di Drive, buat **satu folder per objek** dengan nama ID objek, lalu masukkan 2 fotonya. **Jangan ubah nama file asli.**  
4. Isi Form log (bagian 6\) untuk setiap objek.  
5. Upload **maksimal H+1** setelah sesi.

**Struktur folder Drive**

```
dataset-sampah/
├── raw/
│   ├── plastik/
│   │   ├── PL-F-001/
│   │   │   ├── IMG_20261102_141503.jpg   ← atas
│   │   │   └── IMG_20261102_141511.jpg   ← miring
│   │   └── PL-M-001/ ...
│   ├── kertas/
│   └── kardus/
├── bts/
│   └── F-S01/ ...
└── log_akuisisi   (Google Sheet)
```

**Larangan**

- **Jangan kirim foto lewat WhatsApp/Telegram.** Aplikasi chat mengompres foto dan menghapus EXIF.  
- Jangan edit, crop, atau rotate foto.  
- Upload lewat aplikasi Google Drive atau kabel ke laptop. Jangan lewat Google Photos dengan mode *Storage saver*.

Nama file standar (misalnya `PL-F-001_atas.jpg`) nanti dibuat oleh script dari nama folder dan urutan waktu EXIF. Karena itu aturan "atas dulu" dan "tepat 2 foto" wajib dipatuhi.

## 6\. Pencatatan & Bukti

**Log akuisisi:** isi **Google Form** (link di grup) untuk setiap objek, di hari yang sama dengan sesi. Jawaban otomatis masuk ke Google Sheet `log_akuisisi`.

| Isian | Pilihan / format |
| :---- | :---- |
| ID objek | `PL-F-001` (format salah otomatis ditolak) |
| Kelas | plastik / kertas / kardus |
| Sub-tipe | menyesuaikan kelas (lihat bagian 2\) |
| Anggota | Mafaza / Farhan / Jefri |
| Sesi | `ANGGOTA-S` \+ nomor urut sesi: `F-S01`, `F-S02`, … |
| Tanggal | tanggal memotret |
| Lokasi | kost/rumah / kampus / tempat umum / lainnya |
| Latar | polos / ramai |
| Cahaya | dalam-alami (jendela) / dalam-lampu / luar-terang / luar-teduh |
| Kondisi | bersih / kotor / rusak (penyok/lecek/sobek) |
| Catatan | opsional |

Kalau ada isian yang salah, laporkan ke koordinator data. Jangan mengisi ulang Form untuk objek yang sama.

**Sheet Rekap** (otomatis) menampilkan progres per anggota × kelas, persentase latar ramai, porsi kresek, dan ID duplikat. Sel yang melanggar batas akan berwarna **merah**. Cek rekap sebelum sesi berikutnya untuk tahu kelas atau latar mana yang masih kurang.

**Bukti akuisisi**

- **Foto BTS:** 1–2 foto per sesi yang memperlihatkan tangan \+ HP sedang memotret objek, dengan latar dan lokasi ikut terlihat. Simpan di `bts/<sesi>/`.  
- Wajah sendiri tidak perlu masuk. **Wajah orang lain tidak boleh masuk.**  
- **EXIF jangan dihapus.** Aturan larangan kirim via WhatsApp berlaku juga untuk foto BTS.

## 7\. Etika & Keamanan

1. **Tidak ada wajah, orang, atau plat nomor** di frame.  
2. **Tidak ada dokumen atau data pribadi** (lihat aturan kertas di bagian 2).  
3. **Kebersihan:** pakai sarung tangan atau cuci tangan setelah memegang sampah. Hindari sampah tajam (kaleng sobek, pecahan) dan sampah medis.  
4. **Minta izin** kalau memotret di tempat milik orang lain (warung, kantin, rumah orang). Jangan mengganggu aktivitas di sekitar.

## Lampiran (untuk koordinator data): Setup Google Form

Form disimpan di folder `dataset-sampah/`, dengan respons terhubung ke Sheet `log_akuisisi`.

**Section 1: Identitas**

| No | Pertanyaan | Tipe | Wajib | Validasi |
| :---- | :---- | :---- | :---- | :---- |
| 1 | ID objek | Short answer | ✓ | Response validation → Regular expression → *Matches* → `^(PL|KT|KD)-(M|F|J)-\d{3}$` |
| 2 | Anggota | Multiple choice: Mafaza, Farhan, Jefri | ✓ |  |
| 3 | Sesi | Short answer | ✓ | Regex: `^(M|F|J)-S\d{2}$` |
| 4 | Tanggal | Date | ✓ |  |
| 5 | Kelas | Multiple choice: plastik, kertas, kardus | ✓ | Aktifkan **"Go to section based on answer"**: plastik → Section 2, kertas → Section 3, kardus → Section 4 |

> Catatan: di Google Form, tanda `|` di regex ditulis biasa tanpa backslash. Backslash di tabel di atas hanya untuk keperluan format markdown. Tulis: `^(PL|KT|KD)-(M|F|J)-\d{3}$` dan `^(M|F|J)-S\d{2}$`.

**Section 2: Sub-tipe plastik** → Multiple choice: botol, gelas cup, wadah/tutup, kresek. *After section: go to Section 5\.*

**Section 3: Sub-tipe kertas** → Multiple choice: lembaran utuh, diremas, dilipat/sobek, koran/struk. *After section: go to Section 5\.*

**Section 4: Sub-tipe kardus** → Multiple choice: kotak utuh, potongan/lembaran, penyok/basah. *After section: go to Section 5\.*

**Section 5: Kondisi pengambilan**

| No | Pertanyaan | Tipe | Wajib | Pilihan |

| 7 | Latar | Multiple choice | ✓ | polos, ramai |
| 8 | Cahaya | Multiple choice | ✓ | dalam-alami, dalam-lampu, luar-terang, luar-teduh |
